ADON AJU — PERSONAL RESUME WEBSITE

FILES
- index.html       Home and introduction
- education.html  Education history
- focus.html      Interests, career goal, and experience
- styles.css      Shared styling for all pages
- assets/         Your portrait photograph

TO VIEW
Open index.html in a browser. Use the links in the top navigation to visit the other pages.
Keep the folder structure unchanged so the pages can find styles.css and the portrait.

TO HOST
Upload all files and the assets folder together to a static website host. For GitHub Pages,
keep these files in the same repository folder as your current website files.

REPLACE YOUR WEBSITE FILES USING GITHUB DESKTOP
1. Download and extract this ZIP on your computer.
2. In GitHub Desktop, choose your website repository and select Show in Explorer (Windows)
   or Show in Finder (Mac). This opens the local folder GitHub syncs with your repository.
3. Open the extracted adon-aju-resume folder in another window. Copy index.html,
   education.html, focus.html, and styles.css into the matching website folder you just opened.
   If asked, choose Replace the files with the same names.
4. Copy assets/adon-aju-portrait.png into the website folder's existing assets folder,
   replacing the old portrait. Keep its name and location exactly as shown.
5. In GitHub Desktop, review the changed files, enter a short summary such as "Update resume
   home page", click Commit to main (or your current branch), then click Push origin.
   The live website updates from these saved changes.

If the existing website files are inside a subfolder in your repository, replace them in that
same subfolder and put the portrait in that subfolder's assets folder. Do not add a second
copy of the website in a different folder. Keep the three HTML pages, styles.css, and assets
together, as they are in this ZIP.

PERSONAL DETAILS
School and college years, contact details, and project descriptions were not supplied, so they
have not been invented. Add those details if you would like the website to include them.
